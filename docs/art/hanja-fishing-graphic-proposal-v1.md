# 한자 낚시터 화면 그래픽 제안 v1

2026-10-26. 사용자 요청에 따른 화면 배치·수채 그림체 검토용 제안입니다. 현재 게임 구현 화면이 아니며 게임 코드는 변경하지 않았습니다.

이미지: `hanja-fishing-graphic-proposal-v1.png`

## 화면 구성

- 메인: 가로형 패드 화면 대부분을 수채 연못에 사용합니다. 왼쪽 아래에는 낚시하는 아이·나무 부두, 중앙과 오른쪽에는 큰 선택 물고기 세 마리를 둡니다.
- 위쪽: 왼쪽 현재 지역, 가운데 문제와 다시 듣기, 오른쪽 이번 놀이 진행과 쉬기입니다.
- 아래쪽: 낚시 / 도감 / 내 어항. 물고기 선택 중 이동은 현재 진행 상태를 보존하거나 안전하게 중단하도록 설계합니다.
- 먼저 만나기: 화면 중앙 종이 카드에 큰 한자·훈음·뜻 그림을 함께 표시합니다.
- 릴 감기: 물고기와 찌를 가까이 보여주고 누르기·놓기와 바로 담기를 제공합니다. 게이지 의미는 색과 글자로 함께 표시합니다.
- 내 어항: 잡은 물고기와 도감 타일을 보여 줍니다. 수집과 숙달은 구분합니다.

## 실제 적용 시 조정

- 생성 이미지의 장식적인 한자는 참고용입니다. 실제 한자는 검수된 한국식 자형 글꼴로 별도 렌더링합니다.
- 물고기 중심을 밝고 단순하게 만들고 글자 주변 비늘·수면 반짝임·배경 장식을 줄입니다. 문제를 푸는 동안 보기는 정지합니다.
- 水·木·火는 전체 입문 지역의 그림체 예시입니다. 현재 플레이 시안 범위는 숫자 一~十 그대로입니다.
- 그림의 물고기 색과 한자 연결은 고정 규칙이 아닙니다. 실제 문제에서는 색·위치로 정답을 외우지 않게 배치를 바꿉니다.
- 배경, 아이, 물고기, 한자와 UI를 별도 레이어로 제작할 계획입니다. 이 합성 이미지를 게임 전체 배경 한 장으로 그대로 사용하는 계획은 아닙니다.
- 실제 패드에서 글자 크기·터치 영역·대비·시야와 성능을 확인한 뒤 반영합니다.

## 제작 정보

기본 내장 이미지 생성 도구로 제작했습니다. 생성 지시: 수채화 그림책 느낌의 한국 어린이 한자 낚시 게임 화면 제안 보드. 상단 대형 가로 패드 장면에 연못·낚시하는 아이·水木火 물고기 세 마리·문제 배너·지역·진행·하단 메뉴를 배치하고, 아래에는 먼저 만나기·릴 감기·내 어항 세 장면을 배치합니다. 따뜻한 종이·청록색 물·세이지·복숭아색 물고기, 짧은 한국어 UI, 실제 구현과 구분되는 그래픽 제안으로 생성했습니다.
