# v0.22 — 낱말 문제 다양화

2026-11-03. 첫 숲(풀숲의 보물)의 v0.21 학습 흐름을 보완했습니다. 소스 수정만 했으며 커밋·푸시·배포는 하지 않았습니다.

## 변경

- 첫 모험은 cat·dog 두 낱말부터 소개합니다. 이후 모험은 기존 30개 낱말에서 새 낱말 최대 2개와 복습 낱말을 합쳐 3개를 고릅니다. 모두 소개한 뒤에는 오래된 복습부터 3개씩 순환합니다.
- 선택지는 이미 소개한 낱말에서 뽑습니다. 처음에는 2개, 후보가 쌓이면 3개, 해당 낱말을 혼자 3회 알아본 뒤에는 최대 4개입니다. 익숙해진 단계에서는 비슷한 철자·같은 분류의 후보를 우선합니다.
- 소리→그림, 그림→영어 이름, 빈 글자 채우기, 전체 철자를 사용합니다. 복습에서는 직전 문제 유형을 반영해 듣기와 회상을 번갈아 냅니다. 같은 낱말이 같은 전투 순서에 배치되어도 듣기만 반복되지 않습니다.
- 그림→영어 이름에서는 정답을 자동으로 읽어주지 않습니다. 소리 힌트와 낱말 보기는 도움 사용으로 기록하되 별·진화 보상은 같습니다.
- 낱말을 혼자 3회 알아보고 영어 이름 고르기에도 성공하면 한 글자 빈칸을 냅니다. 빈칸 위치는 돌아가며 바뀝니다. 부분 철자에 혼자 2회 성공하면 전체 철자로 넘어갑니다. 광산 알파벳 진도가 별도 필수 조건은 아닙니다.
- 같은 문제를 다시 열면 선택지·빈칸·힌트 사용을 유지합니다. 도움받은 완료를 독립 정답으로 세지 않습니다.
- 기존 발음, 별 보상, 전투 밸런스는 유지합니다. 새로운 문제 화면은 첫 숲에 적용되며 다른 숲·용암의 화면 흐름은 기존과 같습니다.

## 미리보기

- `http://127.0.0.1:8097/__preview/learning`: 같은 탭의 새로고침·다음 모험에서 연습 진도를 유지합니다. 탭 세션 전용 저장이며 실제 게임의 저장을 덮어쓰지 않습니다. 새 탭에서 처음 시작하면 cat·dog 소개가 정상입니다.
- `http://127.0.0.1:8097/__preview/route-reading`: 익숙해진 단계의 네 낱말 선택지 예시입니다. 검증용 진도를 넣은 일회성 장면입니다.
- `http://127.0.0.1:8097/__preview/route-spelling`: 한 글자 빈칸 예시입니다. 검증용 진도를 넣은 일회성 장면입니다.
- 실제 저장을 사용하는 게임: `http://127.0.0.1:8097/english/`

실행: `python3 tests/preview-server.py`. 다른 검증용 장면은 기존처럼 메모리 저장만 사용합니다.


30개 낱말 순환, 새 낱말 수 제한, 복습 자리 확보, 선택지 확대, 정답 자동 음성 누출 방지, 빈칸 위치 순환, 반복 글자 철자, 재시도 보상 중복 방지, 같은 위치의 낱말도 전체 철자까지 진행하는 것을 확인했습니다.

브라우저에서 1024×600 가로 화면의 네 선택지, 소리 힌트 후 정답·2별 보상, 빈칸 정답·6별 보상을 확인했습니다. 첫 두 낱말을 배운 뒤 새로고침하면 pig 소개로 이어졌고, 검증 화면의 콘솔 오류는 없었습니다. 실제 아이들의 난이도와 학습 효과는 플레이 관찰이 필요합니다.
