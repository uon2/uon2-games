# 영어 모험 v0.17 — 학습과 모험 선택 연결

기준: 0a4c783. 영어 게임 소스만 변경했으며 푸시/배포는 수행하지 않았습니다. 기존 한자 설계 문서의 작업 중 변경은 그대로 보존했습니다.

## 검토와 적용

- 현재 소스에는 용암/문장/상점이 이미 구현되어 있습니다. 이를 다시 만들지 않고 기존 흐름을 다듬었습니다.
- 메인에 탐험 수첩을 추가했습니다. 처음엔 광산, 낱말이 없으면 작업대, 이후 숲/용암으로 한 가지 다음 행동을 안내합니다. 낱말 30개, 문장 12개 수집과 별 잔액을 보여주며 다른 활동도 자유롭게 선택할 수 있습니다.
- 낱말 또는 용암의 중간 문장을 완성하면 회복/검 사거리/대시 중 하나를 고릅니다. 이번 모험에서만 유지되며 상자당 한 번 적용합니다. 회복을 기본 선택해 선택을 어려워하는 아이도 바로 출발할 수 있습니다. 최대 하트 10, 추가 사거리 24, 대시 재충전 최저 0.9초로 제한했습니다.
- 새 문장은 영어 완성 문장·한국어 뜻·기능어 설명을 함께 보여줍니다. 모방 성공을 혼자 이해한 것으로 기록하지 않습니다. 새 문장 두 번 뒤에는 복습을 섞고, 다시 열어 쉬운 문제로 바꾸는 것을 막았습니다. 실제 교육 효과는 두 아이가 뜻을 설명하거나 다른 상황에서 사용하는지 관찰해야 합니다.
- 작업대 난이도를 총 제작 수 대신 낱말별 성공 기록으로 변경했습니다. 많이 플레이했어도 처음 접하는 낱말은 빈칸 한 개부터 시작합니다.
- 숲 별이 지갑으로 추가되지 않는 경로를 수정하고, 용암 보석이 별로 중복 적립되지 않게 했습니다. 문장을 풀지 않은 보상 청구와 정답 연타를 차단했습니다. 상자 완료 기록과 별 지급은 한 번의 저장 갱신으로 처리합니다.
- 접속마다 새로운 runId를 만들고, 보스 뒤 미완료 상자에는 같은 runId를 보존합니다. 새 모험의 보상 번호가 옛 모험과 겹치는 문제를 방지합니다.
- 결과 화면에서 용암 지역 선택으로 돌아갈 때 숲으로 이동하던 연결을 수정했습니다. 풀이 중 일시정지 버튼이 전투를 재개하지 않도록 했습니다.

## 그래픽

`english/assets/forest-clearing.webp`, `english/assets/lava-arena.webp`는 이번 작업에서 내장 이미지 생성 도구로 만든 원화입니다. 정확한 프롬프트는 같은 폴더 README.md에 있습니다. 이미지 포맷만 WebP로 변환해 두 파일 합계 약 550KB입니다.

기존 블록 캐릭터를 유지하고 배경 원화, 구역별 색조, 반딧불/불씨, 타격 파편, 대시 잔상과 그림자를 합성했습니다. 이미지가 아직 로드되지 않았거나 실패하면 절차적 픽셀 배경을 그립니다. 배경은 구역별 Canvas에 한 번 합성해 재사용하며 매 프레임 배경을 다시 생성하지 않습니다. 그림의 테두리는 장식이며 실제 위험 판정은 기존 적/화살/분출구와 같습니다.

BUILD/HTML 자산/SW 캐시는 v17로 맞췄고 원화와 새 world-art.js도 오프라인 캐시에 포함했습니다.

## 검증과 확인할 점

- `node --test tests/*.test.cjs`: 131개 통과. 학습 보상 선택/회차 초기화, 사거리/대시 효과, 문장 모방과 독립 기록 구분, 복습, 미완료 청구 차단, 숲 별 지갑 반영, 처음 보는 낱말 난이도 회귀 검증 포함.
- 실제 브라우저에서 낱말 조립 → 강화 선택 → 다음 전투, 영어/한국어 문장 → 강화, 새 배경을 확인했습니다.
- 일반 게임: `python3 tests/preview-server.py` 실행 후 `http://127.0.0.1:8097/english/`.
- 테스트 진도: `/__preview/menu`, `/__preview/forest`, `/__preview/lava`, `/__preview/sentence`, `/__preview/forge`. 실제 앱을 메모리 저장으로 실행하므로 아이들 저장에는 영향을 주지 않습니다. 서버는 loopback으로만 바인딩합니다.
- 아직 안드로이드 실기기 프레임 속도/멀티터치/아이들 재미·이해도는 확인하지 않았습니다. 이를 자동 테스트 통과로 대신 판단하지 않습니다.
- 음성 파일과 음성 생성기는 변경하지 않았습니다. 기존 설계에서 확인한 상업 배포용 음성 교체는 여전히 별도 과제입니다. 실제 결제/스토어 출시 기능을 이번 작업에서 추가하지 않았습니다.

## 아이들과 관찰할 항목

한 번에 한 가지를 봅니다: 다음 목표를 혼자 고르는지, 뜻을 읽고 조합하는지, 세 선물 중 원하는 것을 골라 사용하는지, 다음 모험에서도 표현을 기억하는지. 접속 연속 기록·시간 제한·실수 감점은 추가하지 않았습니다. '계속 하고 싶은지'는 아이들의 반응을 보고 다음 수정에 반영해야 합니다.
