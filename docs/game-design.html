무료 기본판 30개와 숲은 유지합니다. 유료 용암에서는 영어·한국어 뜻·상황·음성을 함께 배우고 더 큰 별 보상을 얻습니다.

음성: 상업 배포용으로 교체할 필요가 있습니다

확인된 추가 16개는 macOS Samantha로 제작됐습니다. Apple macOS Tahoe 약관 2.F는 시스템 음성의 공개 공유·상업적 이용을 제한합니다. 무료 공개 앱이라고 자동으로 허용되지 않습니다. 당시 이용 조건 검토가 누락됐습니다.

현재 77개 음성 전체의 출처를 점검하고, 앱 파일 배포 권리가 확인된 영어 음성으로 통일하는 것을 제안합니다. Google Cloud Text-to-Speech 등은 생성 음성의 앱 사용을 약관에 따라 안내합니다. 유료 결제 여부 자체보다 선택한 음성의 사용·배포 권한이 중요합니다.

영어 문장 전체 음성과 한국어 뜻 안내를 미리 생성해 오프라인 파일로 제공합니다. 지금은 음성을 교체하거나 서비스 결제를 하지 않았습니다.

근거: Apple 약관 2.F · 적용 계약 안내 · Google 음성 사용 안내 · Google 서비스 약관. 개별 계약·음성 조건은 선택 시 확인합니다.

영어와 한국어 뜻을 함께 배웁니다

영어 문장 → 자연스러운 한국어 뜻 → 상황 그림 → 정상 발음을 한 세트로 제공합니다. 처음에는 따라 만들고, 다음에는 다른 장면에 적용합니다.

영어한국어 뜻장면과 학습
It is a cat.고양이예요.고양이를 가리키며 cat 자리부터 선택
I see a dog.강아지가 보여요.강아지를 발견한 장면에서 see의 뜻 배우기
This is my bag.이것은 내 가방이에요.내 이름표가 붙은 가방으로 my의 뜻 배우기
  1. 영어·뜻·그림을 보고 전체 영어 발음을 듣습니다.
  2. 명사 1칸 → 2개 묶음 → 전체 문장 순서로 도움을 줄입니다.
  3. 한국어 뜻과 다시 듣기는 계속 이용할 수 있습니다. 힌트를 써도 별은 같습니다.
  4. 다음 모험에서 다른 그림에 같은 표현을 사용해 이해와 기억을 확인합니다.

따라 만들기 성공을 독립적인 이해로 기록하지 않습니다. 초기 3개 문장틀 × 4개 명사 = 12문장. 다음 날 새 그림에서 알아보는지까지 관찰합니다.

보상·가격·강화 조건은 초기 제안입니다. 기존 별은 1:1 보존합니다. 가격만 올려 반복을 강요하지 않고 학습 진행과 연결합니다.

플레이 시간에 따른 보상 비교

직접 수치를 바꿔 비교해 보세요. 시간은 실측이 아닌 가정입니다. 용암은 세 문장 상자를 완료한 경우이며, 실패·힌트·재시작 시간을 포함해 현장에서 다시 검증해야 합니다.

  • 측정 목표: 오답·사망·재시도까지 포함한 용암 별/분이 가장 빠른 숲 반복의 2~3배 이상.
  • 앞의 두 문장을 완료하고 실패해도 80별은 보존합니다. 고의 실패 반복이 완주보다 유리하지 않은지도 점검합니다.
  • 무힌트 보상 가산이나 오답 감점은 없습니다. 도움을 사용한 기록과 학습 이해도는 별도입니다.
  • 장착은 1칸, 용암에서 우선 효과 적용. 기존 별이 많아도 높은 강화에는 문장 진행이 필요합니다.

용암 카드 디자인 방향

숲과 같은 교차 검에 암적색 배경과 주황색 용암 균열을 사용합니다. 지역명과 지형 무늬를 함께 표시해 색상 외에도 구분할 수 있게 합니다.

이 페이지는 설계 설명용입니다. 용암 모험·상점·결제 기능이 게임에 적용된 상태는 아닙니다.
