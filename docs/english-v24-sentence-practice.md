# v0.24 — 문장 정답 노출과 반복 출제 개선

2026-11-10. 용암 문장 상자에서 영어 정답을 보면서 빈칸을 풀던 문제와, 이미 모은 낱말의 문장만 반복되던 출제 구조를 수정했습니다.

## 학습 흐름

- 처음 보는 문장은 그림·영어·한국어 뜻·기능어 설명과 기존 음성으로 배웁니다. 이때 답 선택지는 표시하지 않습니다.
- `준비됐어요 · 풀어보기`를 누르면 본보기 음성을 멈추고, 정답 문장과 기능어 설명을 비운 뒤 문제를 냅니다. 힌트도 별도 화면에서 보고 가린 뒤 다시 풉니다.
- 복습은 영어를 읽거나 듣고 한국어 뜻 고르기와, 그림·한국어 뜻을 보고 영어 문장 만들기를 번갈아 냅니다.
- 뜻 선택지는 정답, 같은 명사의 다른 문장 뜻, 같은 문장틀의 다른 명사를 함께 비교합니다. `It is a dog.`에서 강아지만 알아보거나 `This is my bag.`에서 my만 알아보고 찍기 어렵게 구성합니다.
- 문장 만들기는 독립 정답이 쌓이면 명사 한 칸 → 기능어와 명사 두 칸 → 전체 배열로 진행합니다. 두 칸 단계에서는 기능어의 빈칸 위치를 번갈아 바꾸고, 오답 후보도 배운 낱말과 기능어에서 고릅니다.

## 출제와 기록

- 기존 12문장 전체를 대상으로 합니다. 모은 낱말은 최초 출제의 우선순위에만 쓰며, 모르는 낱말은 문장 학습 화면에서 새로 소개합니다. 영어 문장 수나 음성 파일을 늘린 변경은 아닙니다.
- 새 상자를 열 때 최근 세 문장을 제외합니다. 새 문장을 두 개 배웠고 복습 시점이 된 문장이 있으면 복습을 끼웁니다. 후보 중 오래 출제하지 않은 문장을 우선해 일부 문제에 갇히지 않게 합니다.
- 도움받은 문장은 다른 문제 3개 또는 4시간 뒤, 혼자 푼 문장은 다른 문제 5개 또는 24시간 뒤부터 복습 우선 대상이 됩니다. 날짜는 출제 우선순위이며 플레이를 막는 대기 시간이 아닙니다.
- 뜻 이해와 문장 만들기의 독립 정답을 별도 기록합니다. 뜻 문제를 맞혔다고 배열 빈칸이 늘어나지 않습니다. 다음 날의 독립 회상도 바로 재현한 정답과 구별합니다.
- 같은 상자를 다시 열면 문제·보기 순서·빈칸·힌트 사용을 유지합니다. 학습 실적과 별은 중복 지급하지 않습니다. 처음 배우기, 오답, 정답 음성·문장 힌트는 도움 사용으로 기록하며 보상은 동일합니다. 뜻 문제에서 영어 음성을 듣는 것은 문제 입력이므로 정답 힌트로 세지 않습니다.
- 저장 헬퍼가 호출 때마다 새 객체를 만들지 않도록 해 중첩 호출 중 출제 순서·복습 기록이 유실되지 않게 했습니다.

## 검증

영어 관련 184개 테스트 통과. 새 저장과 기존 저장, 12문장 도달, 48회 출제·새로고침 시뮬레이션, 최근 문장 반복 방지, 전 문장 뜻 선택지, 유형 교대·난도 상승, 정답 노출 방지, 재개 시 기록·보상 중복 방지를 확인했습니다.

브라우저에서 배우기 → 풀기, 오답 → 힌트 → 다시 풀기, 뜻 문제, 두 빈칸 문제, 완료 후 진화 보상과 전투 재개를 확인했습니다. 1024×600 가로 및 800×1280 세로 배치를 확인했고 콘솔 오류는 없었습니다. 학습 효과의 크기는 실제 아이들 플레이 관찰이 필요합니다.

```sh
node --test tests/test-mode.test.cjs tests/adventure.test.cjs tests/swarm.test.cjs tests/swarm-learning-combat.test.cjs tests/learning-route.test.cjs tests/sentence.test.cjs tests/craft-learning.test.cjs tests/shop.test.cjs tests/lava.test.cjs tests/version.test.cjs
python3 tests/preview-server.py
```

임시 저장으로 동작하는 검증 화면:

- `/__preview/sentence`: 첫 배우기와 한 칸 문제
- `/__preview/sentence-meaning`: 영어 문장의 뜻 찾기
- `/__preview/sentence-build`: 기능어·명사 두 칸 문제
