# 6급 재시험 공부방

기준일: 2026-11-24. 사용자 요청: 기존 시험 경험을 바탕으로 기출 유형의 문제를 계속 풀고 읽으며 재시험을 준비합니다. 이번 검토·계획·개발 기록은 Notion 대신 이 Git 저장소에 보관합니다.

## 목표와 범위

- 목표는 한국어문회 6급입니다. 하위 급수나 낚시 진행도를 시작 조건으로 두지 않습니다.
- `hanja/practice/`에서 오늘의 문제, 오답 복습, 문제·해설 읽기, 실전 연습으로 바로 진입합니다.
- 기출 원문, 원문에서 확인한 어휘를 활용한 자체 문항, 자체 변형 문항을 구분합니다. 원본의 밑줄·이미지 등 확인하지 못한 요소는 검수 완료로 표시하지 않습니다.
- 정답을 읽은 기록, 도움받아 푼 기록, 처음 혼자 맞힌 기록, 시간이 지난 뒤 맞힌 기록을 구분합니다.
- 이전 점수·취약 유형·재시험 날짜는 미확인입니다. 하루 10문제는 시작 설정이며 최적 분량이라는 뜻은 아닙니다.

## 개발 순서와 완료 조건

1. **기출 검수**: 확보된 112~114회 270문항의 수·번호·종류·정답·범위·추출 제약을 검사하고 문항별 결과를 남깁니다. 필순 이미지 미대조와 의심 답안은 보류합니다. 원본 본문과 HWP는 저장소 외부에 유지합니다.
2. **문제은행**: 검수를 통과한 학습 요소와 기존 배정한자·자체 콘텐츠로 9개 유형을 구성합니다. 출처·검수 상태·공통 학습 요소 ID를 부여하고, 재생성 도구와 범위/문항 수 검증을 제공합니다.
3. **반복 풀이와 읽기**: 10문제, 유형별 연습, 오답 우선 복습, 문항 사이 지연 재확인, 다음 날 복습, 답 가리기, 이어하기를 제공합니다. 읽기만으로 정답/숙달 기록을 올리지 않습니다. 쓰기는 종이 또는 화면에 쓰고 보호자가 확인합니다.
4. **모의시험**: 같은 문제은행으로 90문항·50분의 자체 모의시험을 생성합니다. 응시 중 정답을 숨기고 끝난 후 유형별 결과·쓰기 보호자 채점·오답 복습으로 연결합니다. 위 구성은 확보 자료와 2026-10-26 저장된 기준에 따릅니다. 공식 시험과 난이도·합격 판정이 같다는 뜻은 아닙니다.

## 구현 원칙

- 현재 변경 중인 낚시 코드와 저장 키에 의존하지 않는 독립 경로와 저장 키를 사용합니다. 기존 변경은 이번 커밋에 섞지 않습니다.
- 자동 생성은 승인된 어휘와 답안에서만 조합하며 실행 중 AI가 무검수 문항을 만들지 않습니다. 동일 학습 요소의 다른 형식을 정답 노출 직후 평가용으로 사용하지 않습니다.
- 원문 시각 검수를 대신해 추출 결과를 원문 검수 완료로 승격하지 않습니다. 보류 목록과 자체 대체 문항을 명시합니다.
- 로컬 기기 저장, 파일 내보내기/불러오기, 저장 오류 안내를 제공합니다. 오류 시 저장 성공으로 표시하지 않습니다.
- 휴대폰 화면, 키보드 입력, 한글 조합 입력, 정답 노출 방지, 중복 응답 방지, 시간 경과/재접속, 쓰기 채점 대기를 검증합니다.
