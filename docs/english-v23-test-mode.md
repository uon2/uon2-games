# v0.23 — 전체 개방 테스트 모드

2026-11-04. 영어 게임 v0.23 변경 내역. 이전 전투·낱말 학습 개선과 함께 beta 브랜치에 반영합니다.

지도 왼쪽 위 캐릭터·이름 영역을 **3초 안에 5번** 누르면 테스트 모드를 켭니다. 같은 동작을 반복하거나 지도/설정의 테스트 종료 버튼을 누르면 원래 플레이로 돌아갑니다.

- 광산 5곳, 숲의 모든 밤, 용암 3곳을 진행 순서와 잠금에 관계없이 선택합니다.
- 모든 자동 무기를 사용할 수 있습니다. 빙글검은 최소 Lv.1을 지급하고 상점의 강화 조건을 풀어 직접 강화할 수 있습니다. 원래 보유한 상위 장비는 유지합니다.
- 테스트 지갑은 최소 10,000별, A–Z 블록은 각각 최소 99개로 시작합니다.
- 작업대 낱말 30개, 도감 전체 보기, 방 꾸미기 아이템 각각 최소 3개를 제공합니다.
- 학습 숙달·지역 클리어를 미리 채우거나 무적을 적용하지 않습니다. 문제 단계와 실제 전투는 정상 방식으로 진행됩니다.

`save-session.js`가 평소 저장(`ebw-save-v1`)과 테스트 저장(`ebw-save-v1-test`)을 분리합니다. 모드 선택은 탭별 `sessionStorage`에 두어 같은 탭의 새로고침에서는 테스트 진도를 이어가고, 다른 일반 탭은 원래 저장을 사용합니다. 종료하면 원래 저장으로 돌아가며 다음에 다시 켜면 현재 일반 기록을 복사해 새 테스트를 시작합니다. 정상 저장은 테스트 보상·강화·학습·방 배치로 덮어쓰지 않습니다.

검증: 영어 관련 171개 테스트 통과, `git diff --check` 통과. 5회 입력 조건, 전체 지역 진입, 장비·낱말·꾸미기 개방, 저장 분리, 새로고침 복구, 종료 후 잠금/기록 복원, 저장소 접근 실패를 확인했습니다. 브라우저에서도 5회 클릭 → 강화 → 새로고침 → 마지막 용암 지역 진입 → 테스트 종료를 확인했습니다. 1024×600 가로 및 800×1280 세로 배치를 확인했고 콘솔 오류는 없었습니다.

```sh
node --test tests/test-mode.test.cjs tests/adventure.test.cjs tests/swarm.test.cjs tests/swarm-learning-combat.test.cjs tests/learning-route.test.cjs tests/sentence.test.cjs tests/craft-learning.test.cjs tests/shop.test.cjs tests/lava.test.cjs tests/version.test.cjs
```

실제 게임: `http://127.0.0.1:8097/english/`

별도 저장으로 동작하는 검증 장면: `http://127.0.0.1:8097/__preview/test-mode` (`python3 tests/preview-server.py`). 이 장면의 일반/테스트 저장은 모두 탭 전용 임시 저장입니다.
