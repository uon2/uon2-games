기준: a218f93. 로컬 소스만 수정했으며 커밋·푸시·배포하지 않았습니다.

- 낱말 12 → 30개. 기존 12개와 저장 키 유지. 작업대·도감·보물·내 방은 RECIPES로 연결됩니다.
- 추가: ant, bat, bee, owl, rat, bug, ram, sun, log, net, pen, key, car, jam, map, pot, toy, egg.
- 기존 tier 해금 유지: 작업대는 서로 다른 낱말 4개 이후 tier 2, 모험 보물은 3단계부터 tier 2. 반복 글자 bee/egg의 보물 입력과 중복 보상 방지 수정.
- 새 발음 16개는 Samantha 미국 영어, 효과·변조 없음. sun/egg는 기존 파일 재사용. tools/make_audio.py는 macOS say와 ffmpeg/ffprobe 사용. 시스템 음성 서비스 접근이 제한되면 빈 음성이 생길 수 있어 생성 후 길이를 검증합니다.
- forest-art.js: 승인된 시안을 바탕으로 이끼콩(근접), 나무활(궁수), 돌쿵(돌진), 안개왕(보스)을 Canvas 블록 그림으로 구현했습니다. 시안의 질감을 게임 크기에 맞게 단순화했습니다. 둥근 모루/몽실/토리는 제거했고 플레이어는 선택한 아바타의 AVATAR_PATTERN/AVATARS를 그대로 사용하며 머리·몸·팔·다리에 블록 입체감을 추가했습니다. 수정 정령은 제거했습니다. 검/방패/피격 효과와 전투 수치는 유지했습니다.
- 소개 도감에 이름·역할·등장 단계를 표시합니다. MONSTER_TYPES가 이름/크기/역할의 공통 데이터입니다.
- 1단계 이끼콩, 2단계 나무활 1마리, 3단계 이상 나무활 2마리와 돌쿵 1마리. 기존 몹 일부를 대체하므로 총 몬스터 수는 유지. 보스 구역은 안개왕 단독입니다.
- 궁수: 0.95초 조준선 → 고정 방향 화살 → 2.6초 재충전. 이동으로 회피, 대시 무적/방패 적용, 검으로 준비 중 사격 취소. 구역 종료 시 화살 제거.
- 돌쿵: 체력 4, 느린 접근 → 1초 몸 낮추기/주황색 직선 예고 → 0.75초 고정 방향 돌진 → 1.2초 휴식. 벽에서 정지, 검을 맞으면 돌진 취소. 경로 충돌·방패·회피 검증 완료.

- 방패 아이템 1회, 기존 dog 마법 2회 보호는 그대로입니다.
- 캐시 v6-profile-player에 새 코드와 음성 추가. 새 파일도 모두 포함해서 배포해야 합니다.
