# 영어 블록 월드 v0.18 · 무리 전투

이 문서는 v18 시점 기록입니다. 이후 난이도 조정은 [v19 기록](english-v19-balance.md)을 참고해 주세요.

2026-11-02. 로컬 소스 수정입니다. 배포·커밋·푸시는 하지 않았습니다. 이전 v17 변경 사항에 이어 적용하며 한자 게임 문서는 수정하지 않았습니다.

## 플레이 흐름

무료 씨앗봉으로 바로 모험 → 자동 공격과 이동으로 보석 수집 → 레벨 업마다 3가지 중 하나 선택 → 안전한 영어 보물 → 무기 특별 진화 → 더 많은 무리 → 영어 보물 → 보스 → 마지막 영어 보물과 결과 → 상점에서 다음 무기 준비.

- 한 판은 40초 전투, 55초 전투, 보스로 구성합니다. 학습·선택 시간은 전투 시간에서 제외합니다.
- 적은 가장자리에서 0.65초 예고 후 등장하며 플레이어와 안전 거리를 확보합니다. 두 번째 전투는 두 마리씩 등장하고 적·등장 예고 합계는 24개 이내입니다.
- 2단계부터 궁수, 3단계부터 돌진 몬스터가 섞입니다. 보스 공격은 고정 위치를 먼저 예고합니다.
- 기본 보호막 1회, 자동 공격, 이동, 대시, 충전형 필살기를 제공합니다. 기존 캐릭터와 v17 배경은 유지합니다.
- 새 용암 전투에는 불기둥을 함께 넣지 않았습니다. 무리·궁수·돌진·보스와 문장 학습에 집중합니다.

## 장비와 상점

- 씨앗봉은 무료입니다. 빙글검·관통 지팡이·폭발 봉은 각각 300별이며 한 번 얻은 소유권은 남습니다.
- 상점에서 시작 무기를 1종 선택합니다. 모험 중 구매한 무기를 추가해 최대 3종을 조합하고 각 무기는 전투 레벨 5까지 키웁니다. 전투 레벨과 진화는 새 판에서 초기화합니다.
- 빙글검의 기존 소유·영구 강화·가격 300/450/750 및 문장 진도 조건을 유지합니다.
- 새 전투의 첫 보스 승리에는 저장당 무기 선택권 1장을 제공합니다. 기존 사용자도 새 방식의 첫 승리 때 받을 수 있습니다. 모두 소유했다면 선택권을 보관합니다.
- 소유권·별 차감 또는 선택권 사용은 함께 저장하며 이전 버튼의 중복 클릭도 차단합니다.

## 학습과 보상

- 처음 만난 낱말은 영어·한글 뜻·그림과 발음을 먼저 제공합니다. 본보기를 따라 한 완료는 도움 기록으로 분리합니다. 다시 만난 낱말은 듣고 떠올리며 필요하면 본보기를 다시 볼 수 있습니다.
- 문장은 기존 한국어 뜻·표현 설명·본보기·문장 음성을 활용합니다. 도움을 써도 별과 진화 보상은 같습니다.
- 영어를 완성해야 중간 쉼터에서 다음 전투로 넘어갑니다. 마지막 영어 보물까지 마쳐야 새 지역이 열립니다.
- 보스를 잡고 나가도 마지막 영어 보물부터 이어 할 수 있습니다. 새 숲에도 용암과 같은 이어 하기 방식을 적용했습니다.
- 몬스터 보석은 경험치입니다. 별로 환산하지 않습니다. 기존 별 기록과 새 보석 통계도 구분해 저장합니다.
- 숲의 3개 학습 보상 합계는 단계별 10/12/14/14/25별입니다. 첫 두 보물은 각각 합계의 20%를 내림해 지급하고 마지막 보물에서 나머지를 지급합니다.
- 용암은 문장 보물 40+40+70=150별입니다. 같은 판의 같은 보물은 한 번만 지급합니다.
- 기존 저장의 별·진도·낱말·방 아이템·장비는 유지합니다. 실제 결제나 새 유료 잠금은 추가하지 않았습니다.

- `node --test tests/*.test.cjs`: 179/179 통과(무리 전투 엔진 28개 포함).
- 무료 씨앗봉만 소유한 자동 조작 시뮬레이션: 숲·용암 각 8개 난수 조건, 16/16 클리어. 이동·레벨 선택·진화만으로 전투 98.5~106초, 최저 체력 5였습니다. 실제 아이들의 조작 능력이나 재미를 입증하는 수치는 아닙니다.
