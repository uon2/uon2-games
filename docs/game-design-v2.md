# 영어 블록 월드: 기본판과 용암 확장팩 설계 v0.2 — 즐거운 학습 중심

분석 기준: 로컬 beta, bfc809d. 음성 약관 확인: 2026-09-12. 소스 정적 검토이며 새 실기기 플레이/배포 상태 검증은 수행하지 않았습니다. 이 문서는 제안서입니다. 게임 코드는 변경하지 않았습니다.

## 0. 가장 중요한 목표

즐겁게 배우고, 배운 내용을 써서 목표를 달성하는 게임입니다. 전투 시간·반복 횟수·결제 전환율만으로 성공을 판단하지 않습니다. 영어 문장, 자연스러운 한국어 뜻, 상황 그림, 정상 발음을 한 학습 단위로 제공합니다. 의미를 이해한 뒤 단어를 고르고 문장을 완성하면 별을 얻고 원하는 장비에 가까워집니다.

이 문서는 이전 용암 5별/빙글검 5별안을 대체합니다. 문장 뜻·음성 안내와 쉬운 숲 반복의 경제 우위를 먼저 수정합니다. 숫자는 미검증 초깃값이며 개발 구현이나 유료 음성 구매는 아직 하지 않았습니다.

## 1. 이번에 확정된 제품 방향

사용자 결정: 현재의 알파벳·30개 낱말·작업대·숲속 모험·내 방을 무료 기본판으로 유지합니다. 이전의 무료 12개/유료 18개 제안은 폐기합니다. 새 유료 확장은 용암 모험(문장 학습)과 별을 사용하는 장비 상점입니다. 모은 별은 그대로 사용할 수 있어야 합니다.

권장 판매 단위: 용암 확장팩 1회 해금. 구매 즉시 용암 입문/상점 이용, 이후 지역은 플레이로 개방합니다. 가격과 실제 결제 연결은 이번 설계 범위 밖입니다. 결제와 아이가 게임 안에서 별로 사는 장비는 다른 행위입니다.

## 2. 현재 흐름 및 어긋남

현재 실제 흐름: 첫 광산 완료 → 작업대 개방 → 낱말 1개 제작 → 숲 개방 → 일반전 → 보물 낱말 조립/마법 획득 → 일반전 → 보물 → 보스 → 결과/지도/내 방. 광산 5개가 작업대·내 방·숲과 같은 목록에 늘어서 있습니다.

- 광산 예시는 LETTERS의 알파벳별 1개로 고정입니다. RECIPES 30개와 연결되지 않습니다. 근거: app.js showWordCard, data.js LETTERS/RECIPES.
- 숲 4·5단계는 free:false 및 isPremium 검사로 잠겨 있습니다. 새 정책과 맞지 않아 결제 조건만 제거해야 합니다. 순차 클리어 조건은 유지합니다. 근거: data.js BATTLE_STAGES, battle.js goNights/startBattle.
- 만든 낱말 1개면 숲에 입장하지만 출발 마법은 cat/dog 보유만 확인합니다. 다른 낱말을 만들면 안내에 비해 전투 기여가 작습니다. 근거: battle.js startBattle. 제안: 소유 낱말 중 출발 마법 1개 선택, 효과별 동일한 시작 횟수. 현재 cat/dog 두 개 보너스 변경은 별도 밸런스 검증 후 적용합니다.
- 보물이 미보유 낱말을 직접 획득시킵니다. 작업대는 최초 입장 후 필수성이 약해집니다. 이를 버그로 간주해 보물 획득을 막지 않습니다. 광산/작업대는 준비·복습, 숲은 응용·수집으로 역할을 정합니다.
- 작업대 난이도가 총 제작 수에 따라 상승해 12회면 그림 없이 듣기 모드가 됩니다. 같은 낱말 반복이나 보물 획득으로도 total이 늘 수 있어 새 낱말까지 갑자기 어려워집니다. 근거: craft.js craftLevel, battle.js checkForge. 제안: 낱말별 도움 사용/독립 완성 기록, 처음 접하는 낱말에는 그림과 힌트 유지.
- 현재 stars는 보스 보상이 아닙니다. 승패와 무관하게 endAdventure에서 g.xp를 누적한 값입니다. 일반 보석=전투 레벨업+누적 별이라는 두 역할입니다. 이 사실을 전제로 기존 별을 보존합니다.
- 보석·별·블록·트로피·방 물건이 혼재합니다. 목적을 화면에서 구분합니다: 보석=이번 모험 레벨, 별=누적 구매 재화, 글자 블록=작업대 재료, 낱말 수집품=방 꾸미기, 트로피=완료 기념.
- 현재 premium은 부모 산수 문제로 설정되는 시험용 boolean입니다. 이를 실제 구매 증빙이나 용암 이용권으로 그대로 승격하지 않습니다.

## 3. 새 메인 화면과 지역 구조

메인에는 활동 4개만 둡니다: 배움터 / 모험 / 상점 / 내 방. 항상 위쪽에 내 캐릭터와 별 잔액, 아래에 추천 행동 1개를 표시합니다. 창고·도감은 배움터와 내 방에서 바로 접근합니다.

배움터: 광산 선택(기존 5단계) + 낱말 작업대 + 도감. 모험: 숲속 모험(무료) / 용암 모험(확장). 기존 화면/진도는 삭제하지 않고 진입 구조만 정리합니다. 기존 유저에게 튜토리얼을 강제로 다시 시키지 않습니다.

용암 카드: 숲속 모험과 같은 교차 검 실루엣, 붉은 테두리와 암적색 배경, 검은 현무암 사이 주황 용암 균열. 제목 '용암 모험', 부제 '낱말을 이어 문장 만들기'. 색 외에도 지형 무늬와 지역명으로 구분합니다. 잠금 시 검을 없애지 않고 작은 잠금 배지를 덧붙입니다.

상점은 무료 상태에서 장비와 별 잔액을 미리 볼 수 있습니다. 실제 구매/장착/강화는 확장 이용권 해금 후 제공합니다. 구매 안내는 부모 영역에서만 진행하며 보물 풀이 도중 결제 화면을 띄우지 않습니다.

## 4. 광산 낱말 다양화 — 무료 기본판 개선

30개 낱말을 알파벳에 연결하고 같은 예시 연속 노출을 피합니다. 처음에는 첫 글자 일치 우선(B: bed/box/bus/bag), 복습에는 포함 글자도 가능(E: egg/bed/hen). 강조 글자의 위치를 명확히 보여주고 알파벳 이름과 단어 발음을 들려줍니다. 이것은 글자 찾기 활동이며 모든 철자가 동일한 발음이라는 식으로 가르치지 않습니다.

30개로 모든 알파벳을 덮을 수 없으므로 후보가 없는 글자는 기존 LETTERS 예시를 사용합니다. 예시를 봤다는 이유만으로 작업대 아이템을 자동 획득하지 않습니다. 예시 학습 기록과 소유 낱말은 분리합니다.

## 5. 용암 한 판의 흐름

입장 → 출발 장비 선택 → 짧은 전투 → 안전 지점에서 문장 완성 → 별 즉시 저장 → 다음 전투 → 문장 완성 → 보스 → 마지막 문장으로 보스 상자 열기 → 결과/상점.

문장을 푸는 동안 적·화살·용암 지형·입력·전투 타이머를 모두 멈춥니다. 제한 시간/오답 피해/별 차감은 없습니다. 틀리면 문장 전체 정상 발음을 다시 듣고, 그림·뜻·고정 토큰을 추가해 스스로 마칠 수 있게 합니다. 어려우면 안전하게 모험에서 나갈 수 있고 이전에 확정한 별은 남습니다.

보스 처치 자체는 보석/진도/트로피를 주되 용암 별은 주지 않습니다. 마지막 문장 완성으로 별을 줍니다. 보스 처치 후 문장을 풀지 않고 나가도 보스 기록은 저장하고, 다음 입장 때 미완료 마지막 상자를 다시 열 수 있게 해 보스를 반복해서 잡도록 강요하지 않습니다. 다음 지역 개방은 마지막 상자까지 완료했을 때입니다.

전투 길이 목표: 한 판 약 4~6분, 문장 체크포인트 3개. 실제 두 아이의 플레이를 보고 조정할 목표치이며 현재 측정값은 아닙니다. 처음부터 이동 중 문장 선택/받아쓰기/발음 점수화는 넣지 않습니다.

## 6. 문장·한국어·상황·음성을 함께 배우기

첫 용암 입장은 결제 후 바로 가능합니다. 숲 완주·30개 수집을 추가로 강제하지 않습니다. 새 기능어 is/see/my를 이미 안다고 가정하지 않고 짧은 도입에서 가르칩니다.

체크포인트 한 번의 흐름:
1. 이해: 영어 완성 문장 + 자연스러운 한국어 뜻 + 뜻에 맞는 그림을 함께 표시. 정상 영어 음성을 듣고, 한국어도 원할 때 들을 수 있게 합니다. 자동 소리 반복/매번 긴 강제 재생은 피합니다.
2. 조작: 뜻을 보고 명사 1칸 또는 2개 묶음을 놓습니다. 영어 전체 문장은 '문장 보기', 음성은 '다시 듣기'로 언제든 접근합니다. 한국어 뜻은 기본 표시하며 숙련되어도 사용자가 다시 볼 수 있습니다.
3. 확인: 완성된 영어 문장과 한국어 뜻을 함께 읽고, 전체 영어 발음을 재생합니다. 장비 목표까지 남은 별을 알려줍니다.
4. 적용: 다음 체크포인트나 다음 모험에서 다른 그림·다른 명사에 같은 문장틀을 적용합니다. 같은 답의 위치만 외우게 만들지 않습니다.

예문/뜻/장면:
- It is a cat. / 고양이예요. / 하나의 고양이를 가리키는 장면.
- I see a dog. / 강아지가 보여요. / 플레이어가 강아지를 발견한 장면.
- This is my bag. / 이것은 내 가방이에요. / 플레이어 이름표가 달린 가방을 소개하는 장면.

초기 목록: It is a + cat/dog/pig/fox, I see a + cat/dog/cow/fox, This is my + bed/cup/bag/hat. 3개 문장틀 × 4개 낱말 = 12문장입니다. 영어·한국어 뜻·그림은 콘텐츠마다 검수합니다. 관사나 소유 표현이 어색한 임의 조합을 자동 생성하지 않습니다.

성장: 그림+완성문장 모방 → 명사 1칸 → 묶음 2개 → 단어 전체 배열 → 새 장면에서 적용. 문장별 독립 성공이 쌓이면 도움을 줄여보되 어려우면 바로 되돌립니다. 총 제작 횟수로 처음 보는 문장의 힌트를 없애지 않습니다. 힌트를 써도 별은 동일하게 지급하고, 익힌 정도는 별도로 기록합니다.

문장을 보여준 채 따라 만들기는 도입 단계이며 이를 '혼자 이해함'으로 기록하지 않습니다. 힌트 사용/모방 완료/뜻 선택/새 장면 적용/도움 없는 완성을 구분합니다. 다음 모험에 복습 1개를 자연스럽게 섞고, 학습 단계 선택이 가능합니다. 정답 속도·발음 인식 점수는 초기 평가 지표로 쓰지 않습니다.

문장 토큰은 개별 ID로 관리합니다. 대문자와 문장 부호는 시스템이 처리합니다. 의미상 가능한 복수 정답은 허용하거나 문제 그림/뜻을 명확하게 좁힙니다. 영어 단어 음성을 이어 붙이지 않고 문장 전체를 자연스럽게 녹음/합성합니다.

## 7. 별 경제 — 숲보다 용암 학습의 보상이 확실해야 함

기존 save.battle.stars는 1:1로 wallet.stars에 한 번만 이관하며, 이미 모은 별을 깎지 않습니다. 무료 숲의 적립도 유지합니다. 현재 코드상 몬스터 수는 숲 단계별 10/12/14/14/25마리이고 각각 보석 1개를 떨어뜨립니다. 이는 전부 획득했을 때 이론상 상한입니다. 보스 보석을 못 줍거나 중도 패배하면 실제 별은 적습니다. 현재 실측 분당 획득량은 없습니다.

이전 용암 최대 5별은 숲 한 판보다도 적어, 학습이 많은 지역에 갈 동기가 약합니다. 새 제안은 일반 문장 상자 40별 + 다음 문장 상자 40별 + 보스 문장 상자 70별 = 용암 한 판 최대 150별입니다. 용암 보석은 레벨업 경험치이고 별로 중복 환산하지 않습니다. 보스 처치만으로 별이 생기지 않고 마지막 문장을 완성해야 마지막 70별을 받습니다.

가정 비교(실측 아님): 숲 5단계 25별/4분 = 6.25별/분. 용암 150별/6분 = 25별/분, 약 4배입니다. 숲을 2분에 반복한다면 12.5별/분으로 차이가 2배로 줄어듭니다. '용암이 항상 4배'라고 단정하지 않습니다. 힌트·오답·사망·재시작까지 포함한 실제 용암 별/분이 가장 빠른 숲 반복의 2~3배 이상이 되는지 확인하고 조정합니다.

어려우면 보상을 위한 문제 분량을 늘리지 않고 도움·전투 난이도를 먼저 조절합니다. 첫 두 문장만 마치고 실패해도 80별은 남습니다. 고의 실패 반복의 별/분이 정상 완료보다 높아지지 않는지도 측정합니다. 모든 지급은 runId+checkpointId 중복 방지, 실패/종료 때 확정 보상 보존입니다.

상자 보상은 힌트·재시도 여부에 상관없이 동일합니다. 첫날 보너스/연속 접속/연승 배수/힌트 감점으로 학습을 압박하지 않습니다. 복습 문장도 정상 보상을 주며 반복 자체를 벌하지 않습니다.

## 8. 상점 — 가격 상승과 학습 목표를 같이 설계

빙글검 구매 300별 / 2레벨 강화 추가 450별 / 3레벨 강화 추가 750별을 초기 가안으로 둡니다. 새 잔액 0 기준 구매까지 용암 완주 2판, 이후 강화까지 추가 3판/5판입니다. 숲 5단계 상한으로 구매하려면 12판입니다. 기존 별을 가진 아이는 더 빨리 살 수 있고 이를 과거 플레이 보상으로 인정합니다.

가격만 올려 오래 반복하게 만들지 않습니다. 구매는 별만으로 가능, 강화에는 '서로 다른 문장을 완성하고 새 상황에 사용해보기'라는 콘텐츠 진행 조건을 함께 둡니다. 도움을 받아도 기본 강화 진도는 인정하고 독립 이해는 별도 기록합니다. 상위 장비를 많이 만들기보다 빙글검 1종으로 학습·획득·장착·성능 체감을 검증합니다.

구체적인 가안: Lv2는 용암 첫 구역 완료와 서로 다른 문장 4개 완성, Lv3는 세 문장틀 각각 새 장면 적용 1회. 무힌트/무실수를 필수로 요구하지 않습니다. 같은 답을 반복해서 전부 해금하지 않도록 고유 문장/상황 ID를 사용합니다. 이용권 구매만으로 숙련도가 올라가지 않습니다.

목표 표시 예: '빙글검까지 120별 남았어요. 문장 보물에서 별을 모아봐요.' 완료 가능한 한 가지 목표만 노출하고 결제/강화 팝업으로 전투나 학습을 가리지 않습니다. 아이 둘의 성적이나 별 순위를 비교하지 않습니다.

장비는 영구 소유·장착 1칸으로 시작합니다. 용암에서만 전투 효과 적용을 권장하여 무료 숲의 반복 수급 가속을 막습니다. 빙글검은 접촉 시 적별 재타격 간격을 두고 직접 검 공격을 보조합니다. 수호방패/자석별은 다음 버전 후보이며 가격은 실제 수급 검증 후 정합니다.

## 9. 용암이 숲과 달라야 하는 점

붉은 색상만 바꾼 재탕이 되지 않게 첫 버전에는 '예고 후 터지는 용암 분출구' 하나를 추가합니다. 바닥 균열의 밝기와 표시로 예고 → 분출 → 식는 주기. 입구/문장 안전 지점에는 없고, 궁수/돌진 예고와 구분되게 합니다. 새로운 적을 많이 추가하기보다 기존의 이동·대시·빙글검과 조합해 검증합니다.

중간마다 문장 상자를 열어 다리/문이 열리는 연출로 다음 구역에 진입합니다. 영어는 전투 중 번거로운 퀴즈가 아니라 탐험 진행의 열쇠 역할을 합니다. 문장을 틀려도 다리가 무너지거나 캐릭터가 피해를 받지 않습니다.

## 10. 구현 구조 제안

기존 AdventureEngine을 복사해 lava-engine을 따로 만들지 않습니다. worldId(forest/lava), stageId, questionMode(word/sentence), environment, rewardPolicy로 공통 엔진을 설정합니다. 적/피격/대시/투사체 로직은 공유합니다. UI 렌더러, 학습 문제, 보상 저장은 분리합니다.

- content: letters/words/sentences/worlds/equipment. 단어 난이도(tier)와 유료 권한은 별개.
- access: hasEntitlement('lava-pack'), 실제 결제 어댑터와 개발용 해금 분리. 시험용 premium:true를 실제 구매로 간주하지 않음. 이용권 복원과 진도 백업은 별개 기능.
- learning: 낱말/문장별 seen, independentSuccess, assistedSuccess, 최근 도움 수준. 힌트 보상 차감 없음.
- progression: forest/lava별 cleared, 보스 처치 및 문장 상자 완료 분리.
- rewards: 별 적립/차감/장비 구매를 하나의 저장 갱신으로 처리. 잔액 확인, 보상/거래 ID 중복 차단.
- inventory: 소유 장비, 레벨, 장착 슬롯. 기존 craft.made/room.items와 별개.
- persistence: 기존 ebw-save-v1을 읽는 명시적 마이그레이션, 마지막 체크포인트 저장, 실패 복구. 두 패드는 독립 진도이며 공동 별 지갑은 이번 범위에서 제외.

문장 정답 시: 완료 여부 확인 → 완료 기록과 별 잔액을 같은 저장 객체에 갱신 → 저장 성공 후 연출 → 다음 전투. 구매 시: 권한/잔액/소유 여부 확인 → 별 차감과 소유권을 같이 저장 → 장착 안내. 저장 실패 시 성공으로 표시하지 않고 재시도 안내. 보상 중 새로고침/연타/뒤로 가기를 반드시 테스트합니다.

## 11. 우선순위와 완료 조건

A0. 음성 정리: 아래 13절의 권리 확인·대체 음성 샘플 검수·전체 교체를 새 공개 배포의 선행 조건으로 둡니다.
A. 기본판 정리: 숲 4·5 유료 잠금 제거, 무료30개 확정, 기존 저장 회귀 검증, 광산 예시 순환. 메뉴 개편은 기존 동선과 비교하고 한 번에 전면 변경하지 않습니다.
B. 수직 시제품: 용암 1구역(전투→문장→전투→문장→보스→문장) + 4~6개 문장 + 별 이관 + 빙글검 구매/장착. 개발용 이용권으로만 시험합니다.
C. 두 아이 체험: 즐거움과 함께 문장의 한국어 뜻을 설명하거나 새 그림에 적용할 수 있는지, 다음 모험에도 기억하는지 관찰합니다. 부모 도움 없이 문장 완성 가능한지, 전투가 끊기는 느낌인지, 상점 구매/장착을 이해하는지도 확인합니다. 시험 결과로 전투 길이와 도움 수준 조정.
D. 확장: 세 문장틀 12문장/용암 3구역으로 늘리고 장비 2종을 추가. 효과/화살/분출구 성능을 안드로이드 패드에서 점검.
E. 결제 연결: 앞 단계가 검증된 뒤 실제 구매/복원/취소·보류·오프라인 상태 및 이용권과 저장의 관계를 설계하고 구현.

필수 검증: 기존 캐릭터/30개 낱말/방/별 손실 없음; 무료 숲 5구역 이용; 미구매 용암 진입/장비 효과 차단; 모든 최초 문장에 도움; 풀이 중 전투 완전 정지; 힌트 후 보상 동일; 중복 별/구매 차감 없음; 보스 후 미완료 문장 복구; 지역별 장비 효과 범위; 새 문장 음성 오프라인 재생.

## 12. 앞으로 기능 추가 전 확인할 기준

모든 새 기능은 '어떤 영어를 배우는가 / 아이가 어떤 선택·행동을 하는가 / 무엇을 얻고 어디에 쓰는가 / 무료 또는 어느 확장에 속하는가' 네 항목을 먼저 기록합니다. 새로운 화폐·메뉴·강화 수치를 더하기 전에 이 네 가지가 기존 기능과 연결되는지 확인합니다.


## 13. 음성 권리 검토와 교체 계획

확인: tools/make_audio.py는 macOS say -v Samantha로 음성을 생성합니다. 이번에 추가했던 16개 낱말 파일은 이 방식으로 생성한 것으로 확인됩니다. 현재 파일 전체는 알파벳 26 + 낱말 49 + 안내 2 = 77개입니다. 기존 61개 파일의 생성/권리 출처를 파일 수나 재생 여부만으로 확정할 수는 없습니다.

Apple macOS Tahoe 26 라이선스 2.F는 시스템 음성으로 만든 프로젝트의 개인적·비상업적 사용을 규정하며 공개 공유·상업적 맥락 등의 이용을 제한합니다. 무료 공개 배포가 자동으로 허용되는 것도 아닙니다. 별도 허락이 확인되지 않은 Samantha 출력은 공개 앱용으로 교체하는 것이 타당합니다. 적용 계약은 제품 취득 당시 조건/별도 계약에 따라 달라질 수 있습니다. 이 검토는 문서 기반 판단이며 개별 법률 자문을 대체하지 않습니다.

참조: [Apple macOS Tahoe SLA, 2.F](https://www.apple.com/legal/sla/docs/macOSTahoe.pdf), [적용 약관 안내](https://www.apple.com/legal/sla/). 음질이 자연스럽다는 것과 배포할 권리가 있다는 것은 다른 확인 사항입니다. 기존 작업에서 이 검토를 빠뜨렸습니다.

권장 대안: Google Cloud Text-to-Speech의 일반 제공 음성을 후보로 짧은 샘플을 제작하고, 앱에 포함해 배포하는 용도가 선택한 음성·계약에서 허용되는지 확인합니다. 공식 문서는 생성 음성 파일을 약관에 따라 앱에 사용할 수 있다고 안내합니다. 이것은 모든 목소리/요금제/용도가 무조건 허용되거나 결과물의 독점 저작권이 생긴다는 뜻은 아닙니다. [공식 사용 안내](https://docs.cloud.google.com/text-to-speech/docs/basics), [서비스 약관](https://cloud.google.com/terms/service-terms).

유료로 샀다는 사실만으로 충분하지 않습니다. 음성 모델명/제공자/생성일/허용 범위(유료 앱, 웹 공개, 앱 내 파일 배포, 오프라인 재생)/적용 약관 URL과 사본/결제 또는 계약 증빙을 관리합니다. 성우 녹음은 동일 범위와 편집·반복사용을 포함한 서면 이용허락을 확보하는 대안입니다.

교체 범위: 출처 확인 후 가급적 77개 전체를 같은 영어 화자/억양으로 통일하고, 용암 문장 전체 음성과 한국어 뜻 안내를 추가합니다. 제작 때 합성하고 파일로 앱에 포함하여 플레이 중 API 호출/키 노출 없이 오프라인 재생하도록 합니다. 새 음성 파일 매니페스트·캐시 버전을 바꾸고 이전 파일 잔존 여부를 확인합니다. 권리 확인 안 된 기기 TTS를 파일 교체의 만능 대안으로 취급하지 않습니다.

샘플 검수: A/B/C, cat/cup/egg, It is a cat., I see a dog., This is my bag. 및 한국어 뜻. 알파벳 앞의 'capital' 같은 불필요한 말, 철자 읽기와 단어 읽기 혼동, 과장된 캐릭터 음성, 왜곡된 저속 음성, 끊긴 단어 연결을 확인합니다. 영어·뜻·그림의 적절성은 영어 교육 경험이 있는 사람의 검수를 권장합니다.

이번에는 음성을 생성/교체하거나 결제하지 않았습니다. 공개 배포 상태 변경도 하지 않았으며, 설계와 검토만 업데이트했습니다.
