# 6급 한자 공부방

6급 재시험을 위한 독립 학습 화면입니다. 게임방의 **6급 한자 공부방** 또는 `/hanja/practice/`로 들어갑니다.

- 오늘의 10문제와 유형별 연습
- 오답을 두 문제 뒤에 다시 확인하고 다음 날 복습
- 정답을 가리고 문제·해설 읽기, 한자/한글 검색
- 같은 문제은행의 90문항·50분 자체 모의시험
- 종이/화면 쓰기와 보호자 채점, 중단 후 이어하기
- 화면에 획을 그리는 동안 페이지 고정, 손을 떼면 스크롤 복원
- 브라우저 저장과 JSON 백업/병합, 한 번 방문한 뒤 오프라인 실행

## 실행

저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8098 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8098/hanja/practice/`를 엽니다. `?qa=1`은 실제 학습 기록과 분리한 테스트 저장소이며 서비스 워커를 새로 등록하지 않습니다. QA 기록을 실제 공부 기록으로 불러오지 않도록 테스트 백업 파일명에는 접두사를 붙입니다.

## 데이터와 검증

```sh
python3 tools/build_grade6_workbook.py --check
node --test tests/hanja-workbook.test.cjs
node --test tests/hanja*.test.cjs tests/version.test.cjs
```

`tools/grade6-curation.json`의 직접 작성한 뜻풀이와 기존 공식 배정표·자체 어휘, `tools/grade6-source-elements.json`의 대조한 학습 요소로 `data/bank.json`을 재생성합니다. 원본 폴더가 있으면 HWP 해시와 270문항 추출을 다시 검사합니다. 원본이 없는 환경에서는 커밋된 학습 요소 스냅샷을 사용합니다. 필요하면 `--source-dir`로 검수용 JSON 폴더를 지정할 수 있습니다.

문제은행은 943개 학습 항목에 1,164개 제시 형식을 제공합니다. 300자 훈음, 낱말 221개, 쓰기 낱말 112개, 관계 문제와 성어·기초 필순을 포함합니다. 같은 능력·낱말의 다른 제시 형식은 기록을 공유하며, 독음과 쓰기의 성취는 별도로 기록합니다.

원문 전체의 시각 검수는 완료하지 않았습니다. `docs/grade6-source-review.json`은 258개 문항에서 대조한 학습 요소와 12개 보류 항목을 기록합니다. 자체 모의시험은 공식 기출 재현이나 공식 합격 판정이 아닙니다. 필순은 기존 二·三·十의 7개 기초 문항만 있으며 확장이 필요합니다. 원본 HWP와 원문 전체 문장은 이 경로에 포함하지 않습니다.

## 기록 정책

- `uon2-grade6-workbook-v1` 저장 키를 사용하며 기존 게임 기록과 독립적입니다.
- 해설 읽기와 최근 10분 내 답을 본 문항, 짧은 재확인은 독립 정답에 포함하지 않습니다.
- 첫 독립 정답 뒤 1일, 이후 성공에 따라 3·7·14·30일 간격으로 복습합니다. 출발 설정이며 최적 간격을 검증했다는 뜻은 아닙니다.
- 틀린 문항은 회차 안에서 최대 3개까지 다시 묻고 다음 날에도 확인합니다. 짧은 재확인만으로 오답을 해제하지 않습니다.
- 시험 중 답안과 원래 마감 시각을 저장하며, 시간이 지난 뒤 접속해도 저장된 답안으로 제출합니다. 쓰기를 보호자가 확인하기 전에는 결과가 확정되지 않습니다.
- 백업은 더 최근 항목을 병합하고 중복 합산하지 않습니다. 이 기기에 진행 중인 회차가 있으면 유지합니다. 최근 회차 상세 12개와 누적 항목 기록을 저장합니다.

개발 순서와 사용자 요구는 `docs/grade6-workbook-plan.md`에 기록합니다.
