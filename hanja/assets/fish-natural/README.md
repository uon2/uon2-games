# 사실적인 물고기 게임 원화 — 2026-11-03

내장 `image_gen` 도구로 새로 생성한 투명 배경 게임 일러스트입니다. 실제 촬영 사진이나 전문가가 감수한 생물 도감 도판으로 표시하지 않습니다. 기존 실제 사진 도감은 `../atlas/`에 별도로 보존합니다. 외부 사진을 입력하거나 변형하지 않았습니다.

- `crucian-v1.png`: 붕어를 대상으로 한 은빛·청동빛 비늘과 깊은 몸통. 1774×887 RGBA.
- `carp-v1.png`: 잉어를 대상으로 한 긴 몸통·입 주변 수염·갈색 비늘. 1774×887 RGBA.
- `catfish-v1.png`: 메기를 대상으로 한 긴 몸·매끈한 피부·수염. 2172×724 RGBA.

세 PNG는 생성 결과를 그대로 복사했습니다. 원본 크기와 알파 채널을 유지하며 크롭·배경 제거·색 보정은 하지 않았습니다. 화면에서 원래 종횡비로 축소합니다. 정확한 생성 프롬프트 세 개와 도구 기록은 [generation.json](generation.json)에 있습니다. 공통 방향은 ‘왼쪽을 보는 완전한 측면, 사실적인 자연사 도감의 질감, 약간의 손그림 가장자리, 수채 연못과 어울리는 절제된 색, 투명 배경’입니다.

게임 연결은 `../../js/expedition-art.js`가 담당합니다. 원본에서 확인한 입 좌표를 저장하고 낚싯줄 끝과 공유합니다. 화면 크기는 개체의 저장된 가상 길이에 따라 연속적으로 달라집니다. 작은 화면에서 중형·대형을 각각 같은 최대 폭으로 자르지 않고, 모든 개체에 같은 기준 폭을 적용합니다. 가독성을 위한 완만한 화면 크기 환산이며 실물의 축척 도면은 아닙니다.

시각 검수: 투명 배경·세 어종의 서로 다른 체형·비늘/수염·입 연결을 확인했습니다. 실제 사진과의 전문적인 종 동정·해부학 검수 완료를 의미하지 않습니다.
